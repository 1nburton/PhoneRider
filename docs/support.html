Support

Sketch Rider

Help, feedback, and troubleshooting.

Need Help?

For support with Sketch Rider, please open an issue on the GitHub support page: https://github.com/1nburton/PhoneRider/issues.

Include your device model, iOS version, app version, and a short description of what happened. Screenshots or screen recordings are helpful when available.

Common Steps

  • Make sure you are using the latest version of Sketch Rider from the App Store.
  • Close and reopen the app if the rider or track editor behaves unexpectedly.
  • Restart your device if audio, ads, or purchases do not load correctly.
  • Use Restore Purchases in the app if a purchased rider does not appear unlocked.
